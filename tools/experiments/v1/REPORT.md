## 3. Evaluated models

Every model is fair: a zero-argument factory builds a new agent per episode, and the agent receives one `Observation` per step and nothing else. `always-stay` is a control, not a method. The five registered baselines are reference anchors. The two pack agents are research methods of this pack (see `pack_agents.py`). None of them is an oracle.

## 8. Privileged escape bound (context only, not a model)

## 9. Limitations

- Public development evaluation only. The suite is public and small (10 scenarios), and the pack agents were designed while looking at it, so their numbers can overfit it. Nothing here predicts held-out scores.
- Only `v1-pub-10-route-invalidation` has stochastic fire. The other nine scenarios give the same episode under every seed, so the 100 episodes per model hold 9 + 10 = 19 distinct episodes. Intervals treat every episode as a resampling unit and therefore look more precise than the evidence is. Read them as descriptive (docs/statistics.md, section 9).
- The forecast of the pack agents uses only the public rules in the observation. For deterministic fire it is exact, so on the nine deterministic V1 scenarios the future fire is predictable to every fair model. For stochastic fire it is the earliest possible ignition (pessimistic), with a stretched and a current-fire fallback.
- Metrics trade off. A run can lower the congestion block rate by not moving, and person-time to safety counts every non-evacuee at the step limit. Read each metric with the safety rates.
- The privileged bound ignores other people. With crowds it is usually not attainable, so a gap to it is not all recoverable by any policy.
- Compute cost and wall time are not measured or compared.
- The agents are in-process Python code. The fairness guarantee is the interface contract (docs/evaluation.md, section 4), not a sandbox.
- The pack lives in `tools/experiments/v1/` because the leak guard (`emberbench.leakguard`) allows only fixed top-level directories and keeps JSON assets under `scenarios/public/` and `tests/fixtures/`. Run outputs go to a directory outside the repository.

## 10. Reproduce

```bash
python tools/experiments/v1/run_public_benchmark.py --protocol public-development --out ../emberbench-pack-out
```

The run is resumable: rerun the same command after an interruption. Existing outputs are never overwritten; an output with different bytes stops the run. `index.json` in the output directory is the canonical experiment index. Its golden copy is `tests/fixtures/experiments/v1/public-development-index.json`.
